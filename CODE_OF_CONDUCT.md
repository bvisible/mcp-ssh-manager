# Code of Conduct

This project is for people who run commands on real servers and want to do it
safely. Taking part in it, in issues, discussions and pull requests, means:

- **Be kind and assume good faith.** Disagree with the code, the design or the
  decision, never with the person.
- **Stay on topic and be concrete.** A reproducible report and a clear request
  help everyone; so does saying what you tried.
- **No harassment, discrimination, personal attacks or unwelcome advances**, and
  no publishing other people's private information.
- **Keep secrets out of public places.** Never paste passwords, keys or tokens,
  and do not post the details of a vulnerability in a public issue: use the
  private channel described in [SECURITY.md](SECURITY.md).

The maintainer may edit or remove comments, lock threads and block people who do
not follow this. To report a problem with someone's behaviour, write to the
contacts listed in [SECURITY.md](SECURITY.md); reports are treated privately.
